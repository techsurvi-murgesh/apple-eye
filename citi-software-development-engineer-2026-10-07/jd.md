# Software Development Engineer (C10 Applications Development Analyst) — Citi

## Job Overview

We are seeking a proactive, detail-oriented Software Development Engineer (C10) with strong hands-on development expertise in both Python and Java. In this role, you will be part of a collaborative, high-impact engineering team responsible for designing, developing, and enhancing scalable backend services, data pipelines, and microservices supporting mission-critical enterprise platforms.

As a C10 Applications Development Analyst, you will work across the full Software Development Life Cycle (SDLC) under Agile methodologies—participating in requirement analysis, system architecture discussions, hands-on coding, automated testing, code reviews, and production support.

## Key Responsibilities

### 1. Software Design & Development

- Develop, maintain, and enhance robust, scalable backend applications using Java (Spring Boot / Core Java) and Python (FastAPI / Flask / Django / Scripting / Data Processing).
- Build clean, secure RESTful APIs, microservices, and asynchronous event-driven integrations (e.g., Apache Kafka, RabbitMQ, or JMS).
- Optimize application performance, throughput, memory management, and database query execution.

### 2. Quality Assurance & Engineering Best Practices

- Write clean, modular, and maintainable code adhering to enterprise coding standards and SOLID principles.
- Develop comprehensive automated unit, integration, and component tests using frameworks such as JUnit, Mockito, PyTest, or Unittest.
- Maintain high code coverage and resolve static code analysis findings (e.g., SonarQube, security vulnerabilities).

### 3. CI/CD & DevOps Automation

- Integrate applications with modern CI/CD pipelines (e.g., GitHub Actions, Jenkins, Tekton, Harness).
- Containerize services using Docker and support deployments onto container orchestration platforms (e.g., Kubernetes / Red Hat OpenShift).
- Participate in environment setup, automated deployment validation, and release management.

### 4. Collaboration & Agile Delivery

- Actively participate in Agile ceremonies including Sprint Planning, Daily Standups, Backlog Refinement, and Retrospectives.
- Collaborate with business analysts, technical leads, UI/Frontend engineers, database administrators, and QA teams.
- Conduct constructive peer code reviews and contribute to technical documentation (architecture diagrams, API specs in OpenAPI/Swagger).

### 5. Production Support & Operational Excellence

- Assist in triage, root cause analysis (RCA), and remediation of Level 3 production issues.
- Monitor application health and diagnostics using observability tools (e.g., Prometheus, Grafana, Splunk, OpenTelemetry).

## Technical Qualifications & Skill Requirements

### Core Programming & Frameworks

- Python: Strong proficiency in Python 3.x, data structures, asynchronous programming, scripting, and web frameworks (FastAPI, Flask, or Django) or data manipulation libraries (Pandas, NumPy).
- Java: Solid foundational knowledge of Java 11/17+, OOP design patterns, multithreading, concurrency, collections, and the Spring / Spring Boot ecosystem (Spring MVC, Spring Data, Spring Security).

### API & Integration

- Practical experience designing and implementing RESTful APIs with OpenAPI/Swagger specifications.
- Familiarity with message brokers and streaming platforms (e.g., Kafka, ActiveMQ, or IBM MQ).

### Databases & Persistence

- Experience with relational databases (PostgreSQL, Oracle, SQL Server, or MySQL), including schema design, indexing, and complex SQL queries.
- Exposure to ORM frameworks (Hibernate/JPA, SQLAlchemy) and/or NoSQL datastores (MongoDB, Redis, Elasticsearch).

### DevOps, Cloud & Tooling

- Hands-on experience with version control tools (Git / GitHub / Bitbucket).
- Familiarity with build tools such as Maven / Gradle (Java) and pip / poetry / uv (Python).
- Basic understanding of Docker, Kubernetes/OpenShift, and cloud fundamentals (AWS, GCP, or Azure).
- Knowledge of automated testing frameworks (JUnit, PyTest) and CI/CD tools.

## Educational Background & Experience

- Education: Bachelor's degree in Computer Science, Computer Engineering, Information Technology, or related quantitative field (or equivalent practical experience).
- Experience: Approximately 2-4 years of professional software engineering experience with demonstrable proficiency in both Python and Java.
