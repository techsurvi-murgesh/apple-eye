# Associate – AWS DevOps Engineer — PwC (One cloud / Advisory / Mumbai)

Job Position Title: IN_ Associate _ AWS Devops Engineer _One cloud_Advisory_Mumbai
Location: Mumbai
Practice: One cloud — Advisory
Experience Required: 2 to 4 years
Education: BE / BTech / MTech / MCA / MBA (full-time)

## Job Description & Summary

We are seeking a skilled AWS Infrastructure and DevOps Engineer to design, implement, and maintain cloud infrastructure and CI/CD pipelines on AWS. The resource will work closely with development, operations, and security teams to automate deployments, ensure system reliability, and optimize cloud resources. The ideal candidate has strong experience in AWS, infrastructure as code, automation, and DevOps best practices.

## Responsibilities

- Design, deploy, and manage scalable, secure, and highly available AWS infrastructure.
- Develop and maintain Infrastructure as Code (IaC) scripts using Terraform, CloudFormation, or AWS CDK.
- Build, monitor, and improve CI/CD pipelines using Jenkins, CodePipeline, CodeBuild, or other tools.
- Automate server provisioning, configuration management, and deployment processes.
- Manage container orchestration using Amazon ECS, EKS (Kubernetes), or Docker.
- Implement monitoring, logging, and alerting solutions using CloudWatch, CloudTrail, and third-party tools.
- Ensure security best practices are applied, including IAM policies, network security groups, and data encryption.
- Collaborate with development teams to optimize application deployment and performance on AWS.
- Troubleshoot infrastructure and deployment issues promptly and implement fixes.
- Maintain documentation related to infrastructure setup, CI/CD workflows, and operational procedures.

## Mandatory skill sets

- Proven experience designing, deploying, and managing AWS infrastructure (EC2, VPC, ELB, RDS, S3, IAM, CloudWatch).
- Strong knowledge of Infrastructure as Code tools: Terraform, CloudFormation, or AWS CDK.
- Experience with CI/CD tools such as Jenkins, AWS Code Pipeline, GitLab CI/CD, CircleCI.
- Proficient with container technologies: Docker, Amazon ECS, EKS (Kubernetes).
- Scripting and automation expertise using Python, Bash, or PowerShell.
- Familiarity with configuration management tools like Ansible, Chef, or Puppet is a plus.
- Understanding networking concepts: DNS, TCP/IP, VPN, Load Balancers, Security Groups, NACLs.
- Knowledge of security best practices in cloud environments.
- Experience with monitoring and logging tools (CloudWatch, CloudTrail, ELK stack).
- Excellent problem-solving skills and the ability to work in a fast-paced environment.
- Strong communication and collaboration skills.

## Preferred skill sets

- AWS Certified Solutions Architect (Associate or Professional) or AWS Certified DevOps Engineer.
- Experience with serverless architecture (AWS Lambda, API Gateway).
- Familiarity with Agile and DevOps methodologies.
