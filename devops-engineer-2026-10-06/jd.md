# DevOps Engineer

Minimum Qualifications

Bachelor's degree in computer science, Information Systems or equivalent work experience

3-4 years of recent Linux/Unix administration
3-4 years of scripting experience (Python, Bash, Groovy, etc)
Good understanding of CI/CD workflows
Experience with version control systems like Git, GitHub
Expertise in administering and securing Enterprise Jenkins or GitHub Actions
Experience working with cloud platforms and Kubernetes technologies.
Production experience creating and using Docker images/containers
Experience with configuration management platforms/tools/processes, preferably Puppet or Terraform.
Experience generally with troubleshooting in a diverse technical environment

Preferred Qualifications

Familiarity with AWS including EC2, RDS, ELB, and EKS technologies
2+ years of hands-on experience deploying applications to Kubernetes in a production environment, alongside two or more years of recent Linux/Unix administration, particularly with RedHat systems
Experience working with REST APIs
Leverage AI-assisted development tools and workflows to accelerate automation, enhance code quality, and streamline troubleshooting processes.
Preference will be given to candidates with production experience administering or applying security best practices to managed DevOps tools like Enterprise Jenkins or GitHub Actions
Familiar with networking (OSI layers, DNS) and reverse proxy systems (Nginx, HAProxy, Apache)
Solid understanding of modern software development practices and agile scrum methodologies
