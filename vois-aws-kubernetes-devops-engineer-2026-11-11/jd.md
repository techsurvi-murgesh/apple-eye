## About this Role

We are seeking an AWS Kubernetes DevOps Engineer to manage highly available, scalable and secure Kubernetes and Amazon EKS environments. The role focuses on Kubernetes administration, AWS cloud infrastructure, GitOps, infrastructure as code and CI/CD automation using technologies including Terraform, Argo CD, Helm, Docker and Git. You will contribute to cloud resource optimisation, observability, security and the resilience of business-critical cloud-native applications and services.

## What you'll do

- Deploy, configure and manage Kubernetes and Amazon EKS clusters, supporting availability, scalability and security.
- Apply Kubernetes administration practices across monitoring, logging and resource optimisation.
- Implement GitOps practices and automated infrastructure workflows using Git and infrastructure as code.
- Provision AWS infrastructure with Terraform and develop reusable Terraform modules.
- Develop and manage Argo workflows and Argo CD deployments for continuous delivery, automated testing and declarative GitOps workflows.
- Build and maintain Helm charts, chart repositories and automated Helm-based application deployments.
- Monitor cloud-resource consumption and optimise EKS and Kubernetes environments for performance and cost.
- Implement security practices including role-based access controls, security policies and applicable compliance controls.
- Support resilient cloud-native infrastructure, container orchestration and continuous-delivery processes.

## Who you are

- You have practical experience with Git, Terraform and Amazon EKS.
- You understand Kubernetes and key objects including services, service accounts, network policies, Secrets, ConfigMaps and Deployments.
- You have experience deploying applications through Helm charts and manifests.
- You have knowledge of Docker, Dockerfiles, Source-to-Image and continuous integration tooling.
- You bring AWS cloud, networking, security and platform expertise, including familiarity with VPC, EC2, ECS, S3, EBS, Glacier, ELB and Elastic IP addresses.
- You have experience with AWS CloudWatch, CodeBuild, CodeCommit, Argo CD and GitOps.
- You understand automation using Terraform and AWS CloudFormation templates.
- You have good documentation and communication skills.
- You understand ITIL, SOX and security regulations.
- You have 3–5 years' experience in programming and/or systems analysis using Agile frameworks and experience applying DevOps concepts in cloud environments.
- Experience managing highly business-critical environments is expected, while DevOps certification and relevant experience are preferred.
- Either a degree in IT with three years' cloud-computing experience, or five years' enterprise IT experience.
