# Middle DevSecOps Engineer — Snoonu

Company: Snoonu
Role: Middle DevSecOps Engineer
Location: Qatar (Remote / Global team as advertised)
Experience: 3+ years in DevOps, security, or cloud infrastructure

## About the Job

We are looking for a Middle DevSecOps Engineer to help secure and optimize our cloud infrastructure at scale. In this role, you will help harden our cloud environment, support secure CI/CD practices, and contribute to proactive defense mechanisms across our infrastructure.

This is a hands-on role for someone with solid cloud and DevOps experience who wants to grow their cloud security expertise in a fast-moving environment.

## What You’ll Get Your Hands On

- Implement and maintain secure configurations across AWS and GCP, supporting IAM roles and policies aligned with least-privilege standards.
- Configure and maintain AWS security services (GuardDuty, Security Hub, Inspector, Config, CloudTrail, WAF) to monitor and alert on infrastructure threats.
- Maintain secure network configurations including VPC peering, NACLs, security groups, VPNs, and private endpoints.
- Support secure CI/CD practices and infrastructure-as-code across build and deployment pipelines.
- Support the security of containerized workloads and contribute to API security reviews.
- Work closely with development and operations teams to integrate security with minimal disruption, growing your cloud security expertise along the way.

## The Magic You Bring

- 3+ years of experience in DevOps, security, or cloud infrastructure, especially AWS.
- Working knowledge of AWS services, IAM, and network architecture.
- Experience configuring and maintaining cloud networks, VPNs, and VPCs.
- Understanding of CI/CD pipelines, infrastructure-as-code (Terraform, CloudFormation), and secure DevOps practices.
- Working knowledge of API security, container security, and AWS cloud security services.
- Good analytical and communication skills.

## Bonus Points

- Exposure to security automation or scripting for infrastructure security tasks.
- Certifications such as AWS Certified Security.
