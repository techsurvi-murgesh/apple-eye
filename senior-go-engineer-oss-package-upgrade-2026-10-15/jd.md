# Senior Go Engineer – OSS Package Upgrade & Bazel

Experience: 3–8 Years
Locations: Pune, Chennai, Hyderabad & Bangalore

## Job Summary

We are looking for experienced Go Engineers to manage and execute third-party open-source (OSS) package upgrades in a large-scale monorepo environment. The role involves upgrading Go modules, resolving dependency conflicts, fixing API compatibility issues, troubleshooting build and test failures, and ensuring successful code integration.

The ideal candidate should have strong hands-on experience in Go development, Go modules, Bazel, Linux, Git, and CI/CD pipelines, with the ability to debug complex dependency and build issues.

## Key Responsibilities

- Analyze existing packages, dependency trees, version compatibility, and potential upgrade risks.
- Upgrade Go modules and third-party open-source libraries while maintaining application stability.
- Resolve breaking API changes and update affected downstream code.
- Troubleshoot Go compilation, build, linker, test, and CI/presubmit failures.
- Work with Bazel, go build, and go test to validate package upgrades.
- Manage Git-based code changes, merge conflicts, code reviews, and local patches.
- Maintain Copybara configurations and resolve source synchronization issues.
- Use scripting and automation to improve dependency analysis, debugging, and validation.
- Submit review-ready code changes with proper documentation and test evidence.
- Prepare migration reports covering version changes, remediation, validation results, and outstanding issues.

## Required Technical Skills

- Strong hands-on experience in Go (Golang) development.
- Good understanding of Go modules, semantic versioning, and dependency management.
- Experience with Bazel, go build, and go test.
- Strong debugging skills for build failures, test failures, and API compatibility issues.
- Experience with Git, code reviews, merge-conflict resolution, and patch management.
- Good knowledge of Linux and scripting for engineering automation.
- Experience working with CI/CD pipelines and automated presubmit checks.
- Strong problem-solving, documentation, and communication skills.

## Good to Have

- Experience with Copybara or similar source-synchronization tools.
- Exposure to large-scale monorepos and OSS package maintenance.
- Experience in vulnerability remediation and dependency upgrades.
- Knowledge of generated code, complex dependency graphs, and large-scale API migrations.
- Experience developing reusable automation scripts and upgrade playbooks.

## Experience & Education

- 3–8 years of software engineering experience.
- Substantial hands-on experience in Go development and debugging.
- A bachelor's degree in Computer Science, Information Technology, or a related field is preferred.

## Key Deliverables

- Successful package upgrades with builds, existing tests, and applicable presubmits passing.
- Submission of clean, review-ready code changes.
- Detailed migration reports with validation evidence and patch status.
- Timely identification and escalation of blockers.
- Reliable delivery against assigned upgrade priorities.
