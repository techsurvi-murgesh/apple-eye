## Title and Summary

### Site Reliability Engineer II

### Overview

The Enterprise Monitoring team is looking for a Reliability Engineer II to drive our Application Performance Monitoring and Digital Experience Monitoring strategy forward, by consistently innovating and problem-solving. The ideal candidate is passionate about Site Reliability Engineering, highly motivated, intellectually curious, analytical, and able to maintain a dual focus on strategic projects and real-time operational needs.

## Role

In this position, you will:

- Provide day-to-day usage and configuration support for monitoring tools for internal customers
- Create and update detailed technical documentation
- Partner closely with technical leads and other engineers as needed
- Discuss specific needs with internal customers and management

## All About You

The ideal candidate for this position will have:

- Experience with one or more application performance management tools such as Dynatrace, AppDynamics, Datadog, etc.
- Specific familiarity with Dynatrace strongly preferred
- Ability to confidently navigate a Linux environment
- Ability to use and revise basic automation scripts in a language like Python, Perl or bash
- Ability to participate in an on-call rotation for off hours emergency support
- Familiarity with foundational distributed application concepts
- Familiarity with synthetic end-user monitoring of web application availability and performance, using tools like Dynatrace, Datadog, New Relic, Pingdom, etc.
- Familiarity with container orchestration systems like Kubernetes (K8s) and public cloud platforms like Amazon Web Services (AWS) and Microsoft Azure
- Strong communication skills to explain technical concepts clearly and succinctly
- Time management skills to balance a workload consisting of both new build work and day-to-day operational maintenance
