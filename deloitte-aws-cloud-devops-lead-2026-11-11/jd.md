# AWS Cloud DevOps Lead — Deloitte Technology & Transformation

**Company:** Deloitte
**Practice:** Technology & Transformation
**Experience:** 4–9 years
**Location:** Bengaluru / Hybrid (source JD lists Mumbai)
**Role type:** Hands-on lead — owns cloud architecture, CI/CD, IaC, EKS, DevSecOps, observability, cost optimisation; leads a team of DevOps, platform and automation engineers

## About the role

We're looking for a hands-on AWS Cloud DevOps Lead to build and run a secure, scalable, cost-efficient AWS platform for mission-critical banking applications. You'll own cloud architecture, CI/CD, Infrastructure as Code, EKS, DevSecOps, observability and cost optimisation. You'll also lead a team of DevOps, platform and automation engineers.

## What you'll do

**AWS architecture:** Design landing zones and multi-account structures using AWS Organizations and SCPs. Build VPC networking with Transit Gateway, VPC endpoints, NAT, VPN and Direct Connect. Deliver HA/DR across Availability Zones and Regions.

**CI/CD:** Build reusable pipeline templates for Java/Spring Boot microservices using CodePipeline/CodeBuild/CodeDeploy, Jenkins, GitLab CI or GitHub Actions. Embed security scanning, controlled artifact promotion, and blue-green/canary deployments. Enforce approvals, rollback and release traceability.

**Infrastructure as Code:** Establish Terraform, CloudFormation or CDK standards and reusable modules. Implement state management, drift detection and policy checks. Enable self-service provisioning for application teams.

**EKS platform:** Design and operate EKS clusters, covering node groups, autoscaling, ingress, networking, storage and upgrades. Use ECR, Helm, IRSA or EKS Pod Identity, and the AWS Load Balancer Controller. Build standard deployment patterns and developer self-service.

**DevSecOps:** Implement least-privilege IAM, federated identity, MFA and privileged access controls. Use Secrets Manager, Parameter Store and KMS for secrets and encryption. Use CloudTrail, Config, GuardDuty and Security Hub for posture management. Ensure audit trails and compliance evidence for regulators and auditors.

**Observability and SRE:** Build monitoring with CloudWatch, X-Ray, Prometheus, Grafana and OpenSearch. Define SLOs, lead incident response and RCA, and run DR and resilience exercises.

**FinOps:** Drive cost visibility through tagging, budgets and allocation. Optimise through rightsizing, Auto Scaling, purchasing strategy (Savings Plans, Reserved Instances) and storage lifecycle policies. Report savings to leadership.

**Leadership:** Mentor the team, set engineering standards, lead design reviews and complex troubleshooting, and work across application, security, database and operations teams.

## Key skills required

- Production experience with AWS: EC2, VPC, IAM, S3, ELB, Route 53, KMS and Organizations, plus multi-account networking
- EKS/Kubernetes, Docker, Helm and ECR
- Terraform and/or CloudFormation, plus Python and Bash
- Enterprise CI/CD with Jenkins, GitLab CI, GitHub Actions or AWS Code* services
- CloudTrail, Config, GuardDuty, Security Hub and secure deployment practices
- SRE practices: incident management, DR and high availability
- Experience in a regulated environment, preferably banking or financial services, with awareness of RBI IT governance and outsourcing requirements

Any Degree, Bachelor's degree in computer science, Information Technology, or related field.
