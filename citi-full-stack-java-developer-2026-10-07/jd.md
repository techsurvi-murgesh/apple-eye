## Job Overview

Citi is seeking a talented and driven Full Stack Software Engineer to design, develop, and maintain high-performance, scalable enterprise applications. In this role, you will play a key part in delivering end-to-end solutions by building responsive, modern user interfaces using Angular and robust, resilient backend microservices using Java & Spring Boot.

## Key Responsibilities

- End-to-End Application Development: Design, develop, test, and deploy resilient, scalable full-stack applications with Angular on the front end and Java / Spring Boot microservices on the backend.
- Frontend Architecture: Build modern, responsive, and accessible web interfaces using Angular (v14+), TypeScript, HTML5/SCSS, and state management libraries (NgRx/RxJS).
- Backend & Microservices Engineering: Architect and implement RESTful APIs, event-driven architectures, and microservices following cloud-native principles, secure coding practices, and clean architecture standards.
- Database & Data Management: Design data models, write optimized queries, and interact with relational databases (e.g., Oracle, PostgreSQL) and NoSQL stores (e.g., MongoDB, Cassandra).
- CI/CD & DevOps: Integrate code into automated CI/CD pipelines, containerize applications using Docker, and support deployment onto container orchestration platforms (Kubernetes / OpenShift).
- Quality Assurance & Testing: Write comprehensive unit, integration, and end-to-end tests using frameworks such as JUnit, Mockito, Jasmine, Karma, or Cypress to maintain high code coverage and quality gates.
- Code Reviews & Collaboration: Participate in active peer code reviews, architectural discussions, sprint planning, and Agile ceremonies.
- Security & Compliance: Ensure software aligns with enterprise security standards, data privacy mandates, vulnerability remediation (e.g., SAST/DAST, SonarQube, Snyk), and regulatory compliance requirements.

## Qualifications & Skills

### Required Technical Qualifications

- Core Experience: 2-4 years of professional software development experience in enterprise-grade applications.
- Frontend Expertise:
  - Proficiency in Angular (v12+ / latest versions), TypeScript, JavaScript (ES6+), HTML5, and CSS3/SCSS.
  - Experience in responsive UI design, modular architecture, and frontend performance optimization.
- Backend Expertise:
  - Strong foundation in Java (Java 11/17+) and core object-oriented programming concepts.
  - In-depth experience with the Spring Framework ecosystem (Spring Boot, Spring MVC, Spring Data, Spring Security, Spring Cloud).
  - Proven track record of designing, building, and consuming RESTful APIs and microservices.
- Database Systems:
  - Practical experience with relational databases (PostgreSQL, Oracle, or MySQL) including schema design, indexing, and SQL optimization.
  - Familiarity with ORM frameworks such as Hibernate / Spring Data JPA.

### Preferred Qualifications

- Experience with containerization and orchestration platforms (Docker, Kubernetes, Red Hat OpenShift).
- Experience with messaging/streaming platforms (e.g., Apache Kafka, RabbitMQ).
- Knowledge of Cloud platforms (AWS, GCP, or Azure) and cloud-native architecture patterns.
- Familiarity with caching technologies (e.g., Redis, Hazelcast).
- Experience working in Agile/Scrum delivery environments with Jira/Confluence.
- Financial services or banking domain knowledge is a plus.
