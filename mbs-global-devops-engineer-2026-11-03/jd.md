# DevOps Engineer — MBS Global (Bengaluru)

Role: DevOps Engineer
Location: Bengaluru
Experience: 3 to 5 years
Job Type: C2H (Contract to Hire)
Notice: Immediate to 15 days

## About Position

MBS Global is hiring DevOps Engineers (3-5 yrs) for projects with global clients.

Skills: CI/CD (Jenkins / GitHub Actions / GitLab CI / Azure DevOps), AWS / Azure / GCP, Terraform (IaC), Docker, Kubernetes, Linux administration, Shell / Python / Bash scripting, Git.
Good to have: Prometheus / Grafana / ELK / Datadog / CloudWatch, DevSecOps practices, networking basics (DNS, load balancers, SSL/TLS).

- Design, implement, and manage CI/CD pipelines for automated build, test, and deployment processes.
- Handle application deployments using Jenkins, GitHub Actions, GitLab CI, and Azure DevOps across environments.
- Manage and optimize cloud services on AWS, Azure, and GCP.
- Provision and manage infrastructure using Terraform (Infrastructure as Code).
- Containerize applications using Docker and orchestrate with Kubernetes.
- Perform Linux administration and automation scripting using Shell, Python, and Bash.
- Configure and maintain Git version control and collaborative development workflows.
- Set up and maintain monitoring and observability tools such as Prometheus, Grafana, ELK, Datadog, and CloudWatch.
- Apply DevSecOps practices including security scanning and least-privilege access.
- Support networking basics such as DNS, load balancers, and SSL/TLS.
- Collaborate with development, QA, and operations teams to deliver reliable, scalable, and secure infrastructure.
- Troubleshoot application and infrastructure issues and perform root cause analysis.
- Create and maintain technical documentation and deployment standards.

- Experience with Docker containerization and Kubernetes orchestration.
