## About Position

The DevOps Engineer will be responsible for managing CI/CD pipelines, infrastructure provisioning, and deployment processes across production and non-production environments. This role focuses on ensuring reliable, scalable, and secure cloud infrastructure on AWS while supporting application deployment, monitoring, troubleshooting, and operational stability.

## What You'll Do

- Design, implement, and manage CI/CD pipelines for automated build, test, and deployment processes
- Handle application deployments using Jenkins across production and non-production environments
- Manage and optimize AWS services including Subnet, ElastiCache, MQ, MSK, RDS, and S3
- Configure and maintain AWS networking, firewall rules, and infrastructure security controls
- Provision and manage infrastructure using Terraform (Infrastructure as Code)
- Set up and maintain monitoring tools such as ELK, Dynatrace, Grafana, OpenSearch, and Site24x7
- Perform system administration, OS-level operations, and automation scripting
- Understand application architecture and support deployment workflows for existing projects
- Configure and manage NGINX for routing, load balancing, and web server functionalities
- Troubleshoot issues across EKS, deployments, CI/CD pipelines, and monitoring tools
- Provide support for critical P1/P2 incidents and ensure timely resolution

## Expertise You'll Bring

- Strong experience in DevOps practices, CI/CD pipelines, and Jenkins-based deployments
- Hands-on expertise in AWS services and cloud infrastructure management
- Knowledge of networking concepts, AWS firewall configurations, and Active Directory
- Experience in infrastructure provisioning using Terraform
- Familiarity with monitoring and logging tools such as ELK, Dynatrace, Grafana, and OpenSearch
- Strong understanding of Linux/Unix systems and automation scripting
- Knowledge of Kubernetes (EKS) and container-based deployments
- Experience working with NGINX and application routing configurations
- Strong troubleshooting and debugging skills across distributed systems
- Ability to handle high-priority production incidents (P1/P2) effectively
- Good understanding of application architecture and deployment workflows
