# AWS Site Reliability Engineer — ITC Infotech

## Role Summary

The AWS Site Reliability Engineer is responsible for managing, optimizing, troubleshooting, and supporting cloud infrastructure hosted on Amazon Web Services (AWS). The role involves advanced technical support, incident resolution, automation, security compliance, and infrastructure improvements.

## Key Responsibilities

- Manage and maintain AWS cloud environments
- Handle L3 escalations for critical incidents and complex technical issues
- Design, implement, and support highly available and scalable cloud solutions
- Monitor infrastructure health using CloudWatch and third-party tools
- Perform root cause analysis (RCA) for major incidents
- Implement disaster recovery and backup strategies
- Automate operational tasks using Python, Shell scripting, Terraform, or CloudFormation
- Manage IAM policies, roles, and security controls
- Optimize AWS resource utilization and cloud costs
- Support patching, upgrades, and compliance requirements
- Collaborate with application, security, and DevOps teams

## Technical Skills Required

- AWS Services: EC2, VPC, S3, IAM, RDS, Route 53, ELB/ALB/NLB, Auto Scaling, CloudWatch, Lambda, SNS/SQS, EKS/ECS, CloudFormation
- Operating Systems: Linux (RHEL, Amazon Linux, Ubuntu), Windows Server
- Automation/DevOps: Terraform, CloudFormation, Ansible, Jenkins, Git/GitHub/GitLab
- Scripting: Python, Shell/Bash, PowerShell
- Monitoring/Security: CloudWatch, Datadog, Splunk, Dynatrace, AWS Security Hub, GuardDuty, AWS Config

## Experience

- 5+ years in Cloud Operations/Infrastructure Support
- 3+ years of hands-on AWS administration
- Experience managing production-critical environments
- Exposure to ITIL processes (Incident, Change, Problem Management)

## Certifications Preferred

- AWS Certified Solutions Architect – Associate/Professional
- AWS Certified SysOps Administrator
- AWS Certified Security – Specialty

## Key Competencies

- Incident Management
- Problem Solving
- Automation Mindset
- Stakeholder Communication
- Team Collaboration
- Documentation and RCA Preparation

## Typical L3 Expectations

- Own critical P1/P2 incidents
- Lead troubleshooting efforts
- Mentor L1/L2 engineers
- Drive automation and operational excellence
- Participate in architecture reviews and cloud optimization initiatives
