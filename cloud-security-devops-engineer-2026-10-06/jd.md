# DevOps Engineer — Cloud Security Engineering at Cisco (SSE Control Plane — Umbrella / Cisco Secure Access)

Cloud Security Engineering at Cisco drives the technology that's transforming the way customers secure their networks, and more importantly, their users.

We are currently seeking a DevOps Engineer to join our dynamic and innovative technology team. The successful candidate should have a foundational understanding of software development, system administration, and a passion for learning new technologies and tools related to continuous integration, continuous deployment, and automation.

As a key member of the SSE Control Plane organization, you will be part of a team responsible for the design, development, and operation of key microservices focused on cloud network experience, traffic optimization and insights related that our Umbrella and Cisco Secure Access products offer.

What You'll Do

Support the development and operations teams by automating and optimizing the software delivery process.
Assist in managing the organization's cloud infrastructure, using monitoring tools to maintain system health and security.
Participate in system troubleshooting and problem-solving across platform and application domains.
Collaborate on deployment strategies and testing processes.
Help to create reliable pipelines for deployment to ensure a seamless process from development to production.
Continuously learn new technologies and keep up with the latest trends in the DevOps landscape.
CI/CD (Jenkins): Expert in building/maintaining pipelines for Docker, Terraform, and Helm deployments; skilled in troubleshooting build and pipeline issues.
Infrastructure as Code (Terraform): Proficient in provisioning AWS infrastructure using modules, state management, and pipeline-integrated workflows.
Containerization (Docker): Experienced in containerizing Java, Python, and ReactJS applications and supporting migrations from legacy VM/EC2 environments to EKS.
Kubernetes (EKS): Deep understanding of core K8s objects (Pods, Ingress, Secrets, etc.) with hands-on experience deploying, managing, and debugging EKS workloads.
Development (Java/Python): Proficient in backend development, debugging application-level issues, and integrating services via RESTful APIs.
Version Control (Git): Proficiency in Git workflows (branching, merging, PRs) and managing code repositories in GitLab or Bitbucket.
Observability & Monitoring: Hands-on experience with Prometheus, Grafana, or Splunk to monitor cluster health, application performance, and log aggregation.
Scripting & Automation: Strong ability to automate routine infrastructure or deployment tasks using Bash or Python scripting.
GitOps Fundamentals: Familiarity with modern deployment patterns (e.g., ArgoCD or Flux) to manage state and reconciliation in Kubernetes.
Networking Concepts: Solid understanding of AWS VPCs, Subnets, Security Groups, and Load Balancing to manage connectivity between EKS and external services.
