# DevOps Engineer — Fiserv

Location: Not specified | Full time

## About Fiserv

Fiserv is a global leader in payments and financial services technology, helping clients achieve their best by moving money and information at the speed of innovation. Fiserv is proud to be an Equal Opportunity Employer and is committed to diversity and inclusion.

## What You Will Do

- Design, build, and maintain CI/CD pipelines for multiple environments.
- Adhere to the processes followed for development in the program.
- Track progress against assigned tasks, report status, and proactively identify issues to the Tech Lead and management team.
- Personal ownership and accountability for delivering assigned tasks and deliverables within the established schedule.
- Facilitate a strong and supportive team environment that enables the team as well as individual team members to overcome any political, bureaucratic and/or resource barriers to participation.
- Recommend and implement solutions. Be totally hands on and can work independently.
- Ready to work 24*7 for any technical support required as a DevOps person.
- Continuously improve the existing deployment plan to automate all the activities and make it efficient.
- Stay updated with emerging DevOps tools and practices.

## What You Will Need to Have

- Linux operating system experience; possibly RedHat Certified Engineer (RHCE)
- Good knowledge and hands on experience on tools like Git, GitHub Actions, Bamboo/Jenkins, Maven/Ant, Artifactory
- Strong experience with AWS cloud platform (EKS, EC2, RDS, S3, Route53, IAM, ELB, API Gateway, CloudWatch)
- Manage and optimize deployments on AWS.
- Expertise in CI/CD tools (Jenkins, GitLab CI, ArgoCD, Azure DevOps, etc.)
- Familiarity with version control systems (Git) and branching strategies
- Proficiency in containerization (Docker) and orchestration (Kubernetes)
- Knowledge of security best practices in cloud and DevOps
- Experience with monitoring and logging tools (Prometheus, Grafana, ELK)
- Automate infrastructure provisioning using Infrastructure as Code (IaC) tools (Terraform, Ansible, etc.)
- Ensure system reliability, scalability, and security across environments
- Strong scripting skills in Python, Bash, or PowerShell
- Experience in the automatic package management with Helm to deploy in the Openshift/Kubernetes
- Knowledge of integration and unit test and Behavior Driven Development
- Good problem-solving skills
- Knowledge of serverless computing and event-driven architecture

## What Would Be Great to Have

- Experience integrating to third party applications
- Agile knowledge
- Certifications in AWS or Kubernetes
- Good understanding of the configuration management
- Financial Industry and Core Banking integration experience
- Strong collaboration and stakeholder management
- Ability to work in a fast-paced, agile environment
- Proactive approach to automation and continuous improvement
- Good communication skills both written and verbal
